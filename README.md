# J & A Construction website rebuild

Static rebuild of janda-construction.com (HTML, CSS, JS, no framework). A small Node script assembles the pages.

## Use
```
npm run build         # builds to dist/, images load from the old host's CDN (works for previewing)
npm run serve         # preview dist/ at localhost
npm run images        # run on a machine with normal internet: copies all images into assets/img/
npm run build:local   # builds with images served from /assets/img/ (no dependency on the old host)
```
Deploy the contents of `dist/` to any static host (Netlify, Cloudflare Pages, GitHub Pages, etc).

## Layout
- `src/pages/*.html` page content (front matter sets title, description, share image)
- `src/layout.html` shared header and footer
- `src/css/style.css`, `src/js/main.js`
- `src/gallery.json` gallery photo list
- `build.mjs` builder. Facts that conflict on the live site (`HOURS`, `CONTACT_HOURS`) are constants at the top.
- `FORM_ENDPOINT` env var: set to a form service URL to post the contact form. Left empty it opens an email draft.

## Search (SEO) notes
- Every page has one H1 with the service and city, a unique title (under about 62 characters) and a unique description (under about 160). Structured data (business, breadcrumbs, service, FAQ) is generated by `build.mjs`.
- Service pages: siding, gutters, home remodeling, kitchen, bathroom, basement finishing, home additions, general contractor, custom home builder.
- Roofing is no longer offered and has been removed everywhere. The old source notes in `docs/source/` still mention it because they are a copy of the original site.
- `SITE_URL` controls canonical links, the sitemap and share tags. It is set to the GitHub Pages address in `.github/workflows/pages.yml`. When the real domain (janda-construction.com) points at this site, change it there and set `BASE_PATH` to empty.
- Still needed outside the code: point the real domain at the site, add it to Google Search Console and submit `sitemap.xml`, and keep the Google Business Profile and Yelp listings current.
